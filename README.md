# Siri Aquatic

Responsive aquaculture catalogue website built with React 19, TypeScript and Vite.

## Run locally

```sh
npm ci
npm run dev
```

The development server runs at http://127.0.0.1:5173/.

## Production build

```sh
npm run build
npm run preview
```

The build outputs static files to `dist/`. Configure your host to serve `index.html` for client-side routes.

## Features

- Video hero with crisp vector lettering and a rotating equipment carousel.
- Surface-aware glass navigation with orange active states.
- Six product cards, category filters, search and individual detail pages.
- Glass equipment showcase with synchronized tabs and keyboard controls.
- Interactive pond brief and local enquiry download.
- Logo-inspired swimming fish, section arrivals and reduced-motion support.
- Responsive layouts with self-hosted fonts and local media assets.

## Content and enquiries

This is a catalogue preview. Equipment renders and reference photographs are illustrative. Company statistics, product specifications, certification statements, warranty terms and policy copy require company verification before a public launch. The enquiry form downloads a local brief; it does not submit enquiries to a server. A verified contact endpoint must be integrated for lead delivery.

Source files are in `src/`; images, fonts and video are in `public/`. The website planning document is included for project reference. Build output, dependencies, local hosting metadata, environment files and verification screenshots are excluded from version control.
